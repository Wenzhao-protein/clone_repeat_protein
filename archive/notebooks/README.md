# archive/notebooks

Backup, executed, and standalone copies of notebooks that have been
replaced by versions in [`../../notebooks/`](../../notebooks/).

Patterns kept here:

- `*_backup.ipynb` — manual backups.
- `*_executed.ipynb` — notebooks committed with cell outputs.
- `*_standalone.ipynb`, `hurdler_minimal.ipynb` — earlier single-file demos.
- `codon_optimization_20230331_*.ipynb` — dated experimental notebooks.
