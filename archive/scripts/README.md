# archive/scripts

Legacy scripts retained for traceability. None of these are part of any
maintained workflow — use the canonical entry points in
[`../../src/hurdler/`](../../src/hurdler/) instead.

Notable families:

- `generate_df2_*` — earlier df2 generation pipelines (replaced by `src/hurdler/pipeline.py`).
- `create_*_lookup*.py` — earlier lookup builders.
- `debug_lookup*.py` — interactive debugging helpers.
- `demo_*.py`, `diagnose_*.py`, `find_all_*.py` — one-off analyses.
- `monitor_*.sh`, `run_*.py` — operational helpers tied to retired filesystems.
