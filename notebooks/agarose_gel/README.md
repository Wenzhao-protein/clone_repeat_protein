# notebooks/agarose_gel

Notebooks for the agarose-gel quantification workflow.

| Notebook | Purpose |
|----------|---------|
| `agarose_gel_analysis.ipynb` | High-level agarose-gel analysis notebook. |
| `interactive_analysis.ipynb` | Interactive band picking and quantification. |
| `interactive_gui_launcher.ipynb` | Launcher for the Tkinter-based GUI in `../../agarose_gel_analysis/src/`. |
| `result_analysis.ipynb` | Post-processing of band-analysis results. |
| `result_analysis_clean.ipynb` | Trimmed-down version of `result_analysis.ipynb`. |

GUI source code: [`../../agarose_gel_analysis/src/`](../../agarose_gel_analysis/src/).
Input gel images / SCN files: [`../../agarose_gel_analysis/data/`](../../agarose_gel_analysis/data/).
