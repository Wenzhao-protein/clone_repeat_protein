# Constructs and sequencing results

This directory deposits the HURDLER fragment designs, assembled plasmid
constructs, and Nanopore sequencing results described in the Supplementary
Information.

- [`directory_structure.txt`](directory_structure.txt) is the deterministic SI
  listing generated by [`get_file_tree.ipynb`](get_file_tree.ipynb).
- [`VALIDATION.md`](VALIDATION.md) records GenBank parsing, construct-length
  arithmetic, and circular/reverse-complement-aware design-versus-consensus
  comparisons.
- `extended_armrp/` contains the extended ArmRP fragment, plasmid, and
  sequencing series.
- `single_chain_armrp_assembly/` contains the single-chain/triangle assembly
  designs and final whole-plasmid sequencing output.

CLC project files and small navigation README files are retained as supporting
repository records but are intentionally omitted from the SI tree. The two
comment lines at the top of `directory_structure.txt` make this policy
explicit.
