# golden_gate_fidelity

Published Golden Gate ligation-fidelity supplementary tables (Pryor et al.).
`FileS01`–`FileS14` cover T4 / T7 / HF / LF / DP / FP ligases at
25 °C / 37 °C and 1 h / 18 h incubations. Consumed by
[`../../../notebooks/utils/re_pair_fidelity.ipynb`](../../../notebooks/utils/re_pair_fidelity.ipynb).
