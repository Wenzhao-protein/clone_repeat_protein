# Data

Small, committed reference data that the maintained workflows depend on.
**Generated artifacts do not live here** — they go in `../output/` and
are gitignored.

## Subfolders

| Path | Contents | Provenance |
|------|----------|------------|
| `reference_input/` | Source databases consumed by curation notebooks under `notebooks/utils/`: REBASE link files, NEB buffer activity table, Golden Gate fidelity tables, plasmid FASTA sequences. | External databases (REBASE, NEB, published supplements). |
| `reference_output/` | Curated CSVs derived from `reference_input/` and used by the HURDLER pipeline: `restriction_enzyme*.csv`, `methylation_check.csv`, `plasmid_*.csv`, `orthogonality.csv`, `codon_usage.csv`, `neb_buffer_activity_cleaned.csv`. | Generated by `notebooks/utils/*.ipynb`. Re-runnable from `reference_input/`. |
| `hurdler_analysis_input/` | Inputs consumed directly by `src/hurdler/pipeline.py`. Mirrors a subset of `reference_output/` packaged for the pipeline run. | Generated; safe to refresh from `reference_output/`. |
| `example_batch_query.csv` | Example input file for `python -m hurdler.query --batch`. | Hand-authored. |

## How to refresh

- Update `reference_input/` only when the underlying database changes.
- Re-generate `reference_output/` by running the relevant notebook in
  `notebooks/utils/`.
- Re-generate `hurdler_analysis_input/` from the curated CSVs in
  `reference_output/` if you change the schema expected by
  `src/hurdler/pipeline.py`.
