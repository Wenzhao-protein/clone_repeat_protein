# output

Working directory for **generated** artifacts produced by
`src/hurdler/pipeline.py`, `src/hurdler/success_rate.py`, and the
notebooks under `notebooks/`.

Everything in this folder is gitignored (see [`../.gitignore`](../.gitignore))
except for this README. Re-running the pipeline reproduces the contents.

Snapshots of historically interesting outputs are preserved in
[`../archive/artifacts/`](../archive/artifacts/).
