# codon_opt_benchmark_extended/results

Aggregated, publication-quality outputs from the codon-optimisation
benchmark.

| File | Contents |
|------|----------|
| `complexity_distribution.pdf` / `_reduced.pdf` | Distribution of sequence-complexity scores across iterations. |
| `scatter_plot.pdf` / `_reduced.pdf` | Best-per-iteration scatter plots. |
| `well_color_iterations.csv` | Per-well colour assignment used in the heatmap notebook. |

Raw per-run outputs (`codon_opt_results_*/`, `*.xlsx`) are gitignored.
