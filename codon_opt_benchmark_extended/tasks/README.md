defines one target sequence and the optimiser parameters to use.

| File | Series |
|------|--------|
| `batch_optimization_tasks.csv` | Master task list. |
| `m12_tasks.csv` | M12 series (12-module construct). |
| `m13_tasks.csv` | M13 series (13-module construct). |
