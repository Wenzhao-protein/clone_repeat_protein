# agarose_gel_analysis/data

Input gel images / SCN files for the agarose-gel workflow, organised
by experiment date.

| Subfolder | Contents |
|-----------|----------|
| `2022-12-12_Q6_Q6_Q5_M2_L2AG2_L2BG2_L3AG2_L3BG2/` | Per-band PDFs/PNGs from the 2022-12-12 gel. |
| `wenzhao_runs/` | Per-experiment subfolders, mostly raw `.png` and `.scn` images. |
| `processed_plots/` | PDFs/PNGs previously generated in-place; preserved so notebooks reproduce a consistent figure set. |

Add new datasets as dated subfolders here — never at the repo root.
